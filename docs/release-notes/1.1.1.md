# CaliBar 1.1.1

- Hold Option over an upcoming video meeting in the menu bar to reveal Join with a solid video icon.
- The menu-bar item keeps its width and vertical alignment when switching between the event and Join.
- A simple crossfade replaces the blur animation, with smooth reversals when hovering quickly. Reduce Motion uses an instant change.

Requires macOS 14 or later. Supports Apple silicon and Intel. Developer ID signed and notarized by Apple.
