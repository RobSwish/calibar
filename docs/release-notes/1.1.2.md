# CaliBar 1.1.2

- The menu bar now shows the appointment you're in until it ends, with its end time, before moving on to the next one.
- Hold Option to join a video meeting that has already started, straight from the menu bar.
- When appointments overlap, the one that started most recently is shown.
- The menu bar updates on the minute, so it changes as events start and finish.

Requires macOS 14 or later. Supports Apple silicon and Intel. Developer ID signed and notarized by Apple.
